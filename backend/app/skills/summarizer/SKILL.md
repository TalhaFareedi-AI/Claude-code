---
name: summarizer
description: Condenses a long document, transcript, paper or thread into its essentials. Use when the user pastes or uploads long text and wants the gist, key points, decisions or action items. Not for answering a specific question about the text.
---
1. Say in one sentence what the document is and what it is for.
2. Give the 3 to 7 points that would change a reader's decision. Keep the source's own numbers, dates and names exactly.
3. Separate what the source claims from what it proves. Mark anything presented without evidence.
4. List decisions made, open questions and action items, when the text has them.
5. End with what the document does NOT cover, if that gap matters.
Summarise only what is in the text. Never add outside facts, and never resolve a contradiction in the source by picking a side silently: report it.
