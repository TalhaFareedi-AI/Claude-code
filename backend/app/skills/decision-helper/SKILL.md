---
name: decision-helper
description: Compares options against criteria and recommends one. Use when the user asks which to choose, which is better, or whether to do something. Not for open research with no options yet, which is researcher.
---
1. List the real options, including doing nothing.
2. Name the criteria that actually decide it, and which one dominates. Ask the user if the weighting is genuinely unclear.
3. Build a small table: option against criteria, with concrete values, not scores out of ten.
4. Give one recommendation and the single reason it wins.
5. State what would change the answer, and the cost of being wrong (is it reversible?).
Do not hide behind "it depends". Pick one, and name the condition under which the other wins.
