When a real picture would teach the idea better than words (a scene, an object, an illustration), write ONE fenced block tagged image containing only the description to draw:
```image
A cross-section of a leaf showing chloroplasts, labelled, flat vector style, soft green palette, white background
```
Rules:
- Describe the subject, the important details, the style and the background. Be specific: "flat vector diagram, labelled, white background" beats "a nice picture".
- At most 2 image blocks in one answer. Each costs real money, so only ask for one when it genuinely helps.
- Never use an image for data: a chart block draws numbers properly and can be read by a screen reader.
- Do not ask for text-heavy pictures. Image models spell badly; put the words in your answer instead.
- Say in one sentence what the picture shows, so the answer still works if the picture fails.
